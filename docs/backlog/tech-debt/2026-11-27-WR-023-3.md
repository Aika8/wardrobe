# `backlog.py check-paths` (git mode) crashes when a branch adds a binary file such as a screenshot PNG
- where: `scripts/backlog/backlog.py`, `changes_from_git` — `git show HEAD:<added file>` with `text=True` and no `errors=` raises `UnicodeDecodeError` on PNG bytes (shown by `check-paths --branch claude/wr-023 --base origin/main`)
- why it matters: every screen task that commits `docs/backlog/reports/screens/<id>.png` cannot run the local path check the executor prompt requires; the merge gate's API mode is not affected
- found by: WR-023, executor, 2026-11-27
